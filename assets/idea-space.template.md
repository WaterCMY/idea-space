# 💡 我的想法空间（Idea Space）

> **用途**：长期记录每日想法 / 灵感；可由 WorkBuddy 自动总结；并追踪「还没好思路 / 没解决方法」的想法。
> **怎么用**：把想法发给我（文字、语音转文字都行），说一句「记一下」我就追加进下方「每日记录」；某个想法还没思路就说「这个还没解决」，我归入「待解决清单」。
> **每日总结**：每天固定时间（默认 21:30）我来汇总当天想法 + 回顾待解决清单，结果归档在文末。
> **📂 分类索引**：按主题归类的版本见 → [`想法空间·分类索引.md`](想法空间·分类索引.md)（5 大类：如何用AI / 个人成长 / 认知 / 职场 / 投资）。新条目会同步归入对应分类。
> **🧩 整合版**：素材库（如腾讯文档「知识梳理」）× 我的思考，合并见 → [`想法空间·整合版.md`](想法空间·整合版.md)（每类分 📥摄入素材 + 💡我的思考 两栏 + 交叉点）。
