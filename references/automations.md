# 想法空间 · 自动化配置参考

两个自动化，按 `automation_update` 的 `mode="create"` 创建。把下文 `<WORKSPACE>` 替换为工作区绝对路径（如 `C:\Users\cmy20\WorkBuddy\认知Agent`）。

两者都**只追加、永不改写** `想法空间.md` 原文。

---

## ① 21:30 每日总结（向内的归纳）

```json
{
  "mode": "create",
  "name": "想法空间·每日21:30总结",
  "scheduleType": "recurring",
  "rrule": "FREQ=DAILY;BYHOUR=21;BYMINUTE=30",
  "cwds": "<WORKSPACE>",
  "status": "ACTIVE",
  "prompt": "维护用户的「想法空间」日志，路径：<WORKSPACE>/想法空间.md。现在是每日 21:30 的自动总结时间，请执行：\n1. 用 Read 工具读取该文件。\n2. 在「## 📅 每日记录」中找到运行当天日期（用 date 命令取当前日期，格式如 2026-08-14）对应的小节。\n3. 若当天无条目（或只有「当天未记录内容」占位）：在文末「## 📊 每日总结归档」下追加一条 ### <当天日期> 总结，内容写「（当天未记录内容）」。\n4. 若当天有真实条目：写一段当日总结，提炼今天的思考 / 感悟 / 反思 / 经历主线，按要点列出，不超过 250 字；同时回顾「## 🔥 待解决想法清单」，说明哪些有进展、哪些仍卡住。\n5. 把总结追加到「## 📊 每日总结归档」下，按日期命名（如 ### 2026-08-14 总结）。\n6. 用 Edit 工具修改原文件，不要新建文件、不要改写已有「每日记录」原文、不要擅自删除待解决条目。\n仅做总结与归档，不新增/修改历史归档区。"
}
```

## ② 03:00 做梦（横向的联想 / 跨域链接）

```json
{
  "mode": "create",
  "name": "想法空间·凌晨三点做梦",
  "scheduleType": "recurring",
  "rrule": "FREQ=DAILY;BYHOUR=3;BYMINUTE=0",
  "cwds": "<WORKSPACE>",
  "status": "ACTIVE",
  "prompt": "你是用户的「梦境副脑」。每天凌晨 3 点，趁用户熟睡，做一次\"做梦\"——把白天清醒时按日期/分类归档的想法，在无意识的自由联想里重新链接，找出用户自己没点破的跨域关联、反复出现的暗线、以及值得玩味的大胆假设。\n执行步骤：\n1. 用 Read 读取：<WORKSPACE>/想法空间.md 与 <WORKSPACE>/想法空间·分类索引.md（若存在 想法空间·整合版.md 也一并读）。\n2. 用 Bash `date +%Y-%m-%d` 取当前日期。\n3. \"做梦\"具体做法——从文件里挑 3–6 个分属不同分类/不同日期的条目，做**非显而易见的连接**：\n   - 跨域暗线：例如「与父亲沟通的上位者心态」与「交易里的盈利锚定/过度控制」是否同源；「人生波动理论」与「相同课题重复出现」如何呼应。\n   - 模式提炼：哪些条目在反复出现却还没被显式连起来。\n   - 大胆假设：给用户一个他可能从未想过的连接视角，必须标注 ⚠️假设（请用户批判性看待，可证伪）。\n4. 把这次\"梦境\"写进 <WORKSPACE>/做梦笔记.md：\n   - 若文件不存在则新建，开头写说明\"本文件由每日 03:00 自动'做梦'机制生成，记录跨域联想与暗线，供用户醒来后取用/证伪。\"\n   - 追加 ### 🌙 <当前日期> 的梦 小节，含：① 本日梦境主线（1 句话）② 3–6 条跨域链接（每条格式：\"条目A ↔ 条目B —— 连接点\"）③ 1 条 ⚠️大胆假设 ④ 1 句\"待用户证伪/采纳\"的收尾。\n5. 仅追加，绝不修改 想法空间 任何原文；不在做梦笔记里改写既有内容。\n6. 若当天想法空间无新增条目，则对已有材料做一次更深度的重新链接，不空跑。\n语气：像半梦半醒的旁白，有诗意但不玄学，关键信息可证伪。"
}
```

---

## 创建方式

在对话中说「配置 21:30 总结」/「设置凌晨三点做梦」时，直接把对应 JSON 里的 `prompt` 作为 `automation_update` 的 `prompt` 参数发出即可（其余字段照填）。
